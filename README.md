# 🐆 ПАНТЕРА ТИМ — сайт кибер-прайда

Официальный сайт Discord-прайда **ПАНТЕРА ТИМ**: Даня, Валера, Максим и Рита.

**Живой сайт:** https://resokau.github.io/panthera-tim/
**Discord:** https://discord.gg/ranMNxS6A

## Что внутри

- 🐆 Неоновая SVG-пантера: глаза следят за курсором, по клику рычит (WebAudio-синтез)
- 👥 Состав прайда с часами в Dota и клик-фразами
- 🎮 8 дисциплин: Dota 2, Standoff 2, Chicken Gun, Minecraft, Roblox, Among Us, Brawl Stars, Geometry Dash — со ссылками на вики
- 🤦 Мемы про Даню (который меньше всех фидит — официально)
- 💬 Фейк-чат прайда + гостевая книга
- 🔮 Оракул: Даня-8 билл, игра вечера, генератор ников
- 🎯 Аркада «Поймай пантеру» (рекорд в localStorage) + тир реакции
- 🌈 КРИНЖ-РЕЖИМ: радуга, Comic Sans, взрывы эмодзи, глиттер-хвост
- 📻 Мем-радио: цирк, полка, 8-бит (реальные MP3 + синт-хардбасс) и визуализатор
- 🏅 17 достижений с тостами
- 🕹 ПРАЙД-ДРАЙВ 3D — играй за каждого из прайда (Three.js)
- 📊 КРИНЖ-МЕТР, тикающий счётчик «Даня в доте», УГАР-режим, конами-код и т.д.

## Структура

```
├── index.html        # разметка
├── css/style.css     # все стили
├── js/audio.js       # аудио-движок: звуки, мем-радио, визуализатор
├── js/main.js        # вся логика: игры, анимации, достижения
├── js/game3d.js      # 3D-игра на Three.js
├── js/three.min.js   # Three.js (self-hosted)
├── avatars/          # аватарки прайда
├── images/           # мемы и картинки (Wikimedia Commons)
└── sounds/           # треки для радио (свободные лицензии)
```

## Запуск локально

Просто открой `index.html` в браузере. Или:

```
npx http-server -p 8080
```

## Деплой

GitHub Pages от ветки `main` — пушишь, и через минуту сайт обновлён.
